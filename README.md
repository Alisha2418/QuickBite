# QuickBite - Food Order Management System

A simple Food Order Management System developed using Git & GitHub
version control practices for the QuickBite Technologies Pvt. Ltd. scenario.

## Features
- Add Food Item (Item ID, Name, Category, Price)
- Display Food Item Details
- Search Food Item by ID
- Delete Food Item

## Technologies Used
- HTML
- CSS
- JavaScript (localStorage)

## Branching Strategy
- main - stable, production-ready code
- develop - integration branch for features
- feature/add-item - Add Food Item functionality
- feature/search-item - Search Food Item functionality

## How to Run
Open index.html in any web browser.
